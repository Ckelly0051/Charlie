# GridIron IQ 1.12.0-51 Smoke

1. Open `Reports` -> `Defense`.
2. Confirm `Opponent Offense by Play Type` shows the opponent's calls against
   our defense: Run Inside, Run Outside, and the charted pass depths.
3. Click `Snaps`, `Yds/Play`, and `Stop Rate`; confirm the rows reorder.
4. Select a play-type row; confirm film contains only that play type and Next
   stays in the selected cohort.
5. Switch `Full season` and `Current game`; confirm the table updates.
6. Open Season Self-Scout and confirm down-and-distance labels show `&`, never
   literal `&amp;`.

No migration or stored-data rewrite occurs in this build.
