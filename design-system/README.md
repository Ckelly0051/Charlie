# GridIron IQ Design System

`tokens.css` is the implementation source of truth for shared visual tokens.
`plex.css` contains the bundled IBM Plex faces, and `material.css` contains
shared component primitives.

The coach-approved usage and acceptance rules live in
`../docs/VISUAL-SYSTEM-RULES.md`. Do not infer token meaning from color values
alone or create route-local replacements for shared palette and typography
roles.
