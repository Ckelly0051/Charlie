Foundations · Which system

Compose three systems.
Adopt none of them whole.

A constraint that decides most of this: the app is vanilla JS with no framework and ships as one file. Every major design system's actual value is delivered as React components we cannot use. So the real question is not "which component library" — it is whose design language we borrow, and for what.

Decided: IBM Plex is the type family — Sans for interface, Condensed for football numerals, Mono for data and timecode. Already validated as easy to read and appropriately heavy.

The candidates, judged for this app

Radix ColorsMIT · pure CSS
A 12-step scale per hue where every step has an assigned job — 1–2 backgrounds, 3–5 interactive states, 6–8 borders, 9–10 solid fills, 11–12 text. Dark scales are designed, not derived. No framework, no build step: it is CSS custom properties.
Take — color architecture
IBM CarbonApache-2.0
Best-in-class data table anatomy and the layer model. Enterprise-neutral greys and IBM Blue are the parts that would make us look like an admin console.
Take — data patterns only
Adobe SpectrumApache-2.0
The only major system built for pro tools where content is the hero and chrome must recede. Its darkest theme exists so media dominates — the closest published precedent for Break Down's theater.
Take — theater precedent
PrimerMIT · GitHub
Excellent dense dark UI that reads as a tool rather than enterprise software. Strong precedent, but it overlaps Carbon without beating it on tables.
Reference only
Fluent 2MIT · Microsoft
Tempting because we are Windows-only, but current Fluent is soft, rounded and consumer-leaning — the opposite of the broadcast-hard direction.
Reject
Open PropsMIT · CSS vars
Not a design system — a token set. Useful fallback if we want ready-made spacing/easing scales without adopting anyone's opinions.
Optional

The recommended stack

TypeIBM Plex — Sans / Condensed / Mono, embedded via the existing bundle-font pipeline.
ColorRadix Colors architecture, tuned cool — 12 steps with assigned roles, so an accent can never quietly come to mean everything.
DensityCarbon table anatomy, row-height scale and 8px rhythm, at our 44px touch minimum rather than Carbon's 32/40.
TheaterSpectrum's content-is-hero principle, plus one surface below the app floor that none of them define: film.
IdentityOurs alone. Field numerals, yard-grid structure, first-down yellow. No system ships this.
