GridIron IQ · design direction

Broadcast control room,
not a dashboard

The current app reads as a re-skinned desktop utility because that is what it is: a color layer applied over legacy markup, with the system font stack and no structural identity. Native routes are the opportunity to make it actually designed.

Two worlds

Theater

The film is the hero

Chrome recedes to near-black so the video is the brightest object on screen. Nothing competes with the play.

Deck

Data is dense and bright

Analysis surfaces lift, tighten and sharpen. Reading 60 rows should feel different from watching film.

Color carries football meaning

Line of scrimmage — blueCurrent. Selected play, active route, where you are right now.
First-down line — yellowTarget achieved. Conversions, success, the thing you were trying to do.
Turnover — redLoss of possession and destructive actions only. Never decorative.

What changes

Scoreboard typography

Condensed tabular numerics for every football number. Currently the app uses the raw system stack — the single biggest reason it reads generic.

Field-derived structure

Yard-line rules and hash ticks as real dividers. field-strip exists in production CSS exactly once today.

One accent, one meaning

Cyan currently means everything, so it means nothing. Blue is current, yellow is achieved, and that is all.

Deliberate density

Every surface is the same mid-grey at the same elevation. Contrast between theater and deck replaces uniform flatness.

Constraint that shapes all of this: the product is Windows-only and ships offline as a single file. That rules out webfonts — and makes Bahnschrift a free win, since it ships with Windows 10+ and gives a true condensed scoreboard voice at zero bundle cost.
